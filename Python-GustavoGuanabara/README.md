# Python-GustavoGuanabara
# 🎓 Exercícios do Curso de Python - Curso em Vídeo

Este diretório contém a resolução dos desafios propostos no curso de **Python 3** ministrado pelo professor Gustavo Guanabara no canal Curso em Vídeo.

O curso abrange desde os conceitos mais básicos de lógica de programação até estruturas de dados mais complexas e modularização.

---

## 💻 Desafios Resolvidos neste Diretório:

Aqui estão alguns dos principais conceitos praticados nos arquivos deste diretório:

* **Tratamento de Dados e Operações Aritméticas**:
  * `antecessor_sucessor.py` - Lógica matemática básica.
  * `dobro_triplo_raiz.py` - Operações e funções matemáticas.
* **Condicionais (If/Else) e Estruturas de Decisão**:
  * `caixa_eletronico.py` - Estrutura lógica de saques e notas.
  * `calculadora_emprestimo.py` - Análise de crédito e aprovação de empréstimo.
  * `Jogo_adinhacaoV1.py` - Jogo interativo contra o computador usando a biblioteca `random`.
* **Estruturas de Repetição (While/For)**:
  * `contagem_regressiva.py` - Estruturas de controle de fluxo de repetição.
* **Organização de Dados**:
  * `ordem_da_lista.py` - Manipulação e ordenação de elementos dentro de listas.
